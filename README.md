# Projeto_Series_Temporais
Projeto de Análise de Serie Temporais - Vendas
Esse projeto de nível intermediário foi desenvolvido em Python e R para análise de um base de dados de vendas disponibilizado pelo Kaggle. 
O objetivo é de aplicar técnicas de séries temporais para identificar padrões de comportamento nas vendas, analisando os componentes como tendência, sazonalidade e autocorrelação, além de posteriormente desenvolver um modelo para previsão. 
O projeto também possui um componente de automação: ao executar o script principal, as análises e visualizações são geradas automaticamente e armazenadas na estrutura de saída do projeto. 

# Tecnologias
- Python;
- R;
- Matplotlib;
- Statsmodels;
- Jupyter Notebook.

# Etapas do Projeto
1. Estruturação e organização do projeto.
2. Importação e exploração da base de vendas.
3. Análise da estrutura e qualidades dos dados.
4. Pré-processamento.
5. Construção da série temporal.
6. Geração automática do gráfico da série.
7. Decomposição da série temporal.
8. Análise de tendência e sazonalidade.
9. Análise de ACF e PACF.
10. Teste de estacionariedade.
11. Modelagem da série temporal.
12. Previsão de vendas.
13. Avaliação do Modelo.
14. Documentação dos resultados.
